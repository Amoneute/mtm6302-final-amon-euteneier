# StudentWallet — Student Budget Tracker

A budget tracker for college and university students. Users set a monthly budget, record income and expenses by category, and see how much they have left. Data is saved in the browser with Local Storage. There are no accounts, bank connections or APIs.

**Developer:** Amon Euteneier
**Client:** Katok
**Course:** MTM6302 — Web Development with JavaScript

## Planned Features

- F1 — Monthly Budget
- F2 — Income and Expenses
- F3 — Expense Categories
- F4 — Financial Overview
- F5 — Transaction History

## Technologies

HTML, CSS, JavaScript, DOM manipulation, Local Storage
